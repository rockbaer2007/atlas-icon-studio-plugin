ATLAS PLUGIN

ATLAS Icon Studio

Icons ansehen, SVG-Pfade vorbereiten und ein Home-Assistant-Iconset mit dem Präfix atlas: exportieren.

Beispiel

Home-Icon

Für atlas:-Icons werden SVG-Dateien mit einfachen <path>-Elementen unterstützt. PNG/JPG kann hier angesehen und separat gespeichert werden, aber nicht als Vektor-Icon in das Iconset.

Vorschau

Home Assistant-Aufruf

atlas:home funktioniert, sobald das exportierte Iconset als Frontend-Ressource in Home Assistant geladen ist.
